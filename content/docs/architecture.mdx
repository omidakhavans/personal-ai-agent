Phase 1 used Codex as the runtime. Phase 2 makes the parts Codex handled implicitly visible in application code.

```text
Agent = runtime + model + tools + instructions + state
```

The runtime coordinates stage order and persistence. The model interprets bounded inputs. Tools collect local evidence and explicitly supplied resources. Instructions define each stage's behavior. State records exactly what happened.

## Runtime shape

```text
CLI -> Orchestrator -> state.json -> stage executor -> Markdown artifacts
```

The orchestrator owns deterministic rules, such as `review-blog` happening after `write-blog` and human approval happening before social drafting. Stage executors own capability-specific logic, such as deciding that insufficient evidence should block a run.

## Grounding boundary

The model does not receive unrestricted filesystem or network access.

```text
repository or supplied resource
  -> bounded collector
  -> source identifiers
  -> model interpretation
  -> schema validation
  -> Markdown artifact
```

This does not prove that every model interpretation is correct. It makes important claims traceable and gives a human reviewer a clear evidence trail.

## Review and approval boundary

`review-blog` fingerprints the exact saved article, compares it with the prepared evidence context, and blocks material grounding or technical problems. A passing review is still only `ready_for_human_review`.

The next `approve-social` stage pauses the run until its owner explicitly approves social transformation. LinkedIn and X stages require that approval and the matching review fingerprint, then write drafts only. No stage publishes content.

## Safety boundary

Shareable `state.json` and Markdown artifacts use safe labels rather than absolute local paths. Local paths necessary for resume are stored separately in ignored, owner-only local configuration. Source text receives best-effort credential redaction before it reaches the model.

Remote resource fetching accepts only explicitly supplied public HTTPS URLs, rejects private and reserved network addresses, and checks redirect destinations. This prevents a future model or document from turning the runtime into a way to read an internal service.
