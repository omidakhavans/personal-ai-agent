## Requirements

- Python 3.11 or later for the runtime.
- An OpenAI API key only when executing a real model-backed stage.
- Node.js 22 or later when developing this documentation site.

## Run the runtime

From the project root:

```bash
export OPENAI_API_KEY="<your-api-key>"
python -m personal_ai_agent run "What I learned building tool calling" \
  --repository "/path/to/project-to-research" \
  --resource "/path/to/notes.md"
```

The CLI prints a run ID and status. Use the ID to inspect or resume work:

```bash
python -m personal_ai_agent show-state <run-id>
python -m personal_ai_agent resume <run-id>
```

The API key remains in the process environment. It is not written into state, reports, or documentation artifacts.

## Run tests

```bash
python -m unittest discover -s tests
```

Tests use fake model clients. They prove workflow contracts without making paid calls or fetching live resources.

## Develop the documentation site

```bash
npm ci
npm run dev
```

Build the static export locally:

```bash
npm run typecheck
npm run build
```

The generated `out/` directory is ignored by Git. GitHub Pages builds the same export with a repository base path after the workflow is enabled.
