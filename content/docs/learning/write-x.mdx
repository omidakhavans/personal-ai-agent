---
title: Write X
description: Create a concise approved single post or technical thread from the reviewed article.
---

`write-x` reads the same approved reviewed article and writes `x-draft.md`. It selects `single` only when one post is enough, or a two-to-five-post `thread` when the idea needs progression.

Every post and technical insight cites known evidence IDs. The runtime rejects posts longer than 280 characters, stale reviews, missing approval, and invented references before saving the draft.

This is controlled generation: trusted source material, explicit objectives, structured output, and narrow boundaries keep the model useful without letting it invent a separate story.
