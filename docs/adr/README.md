# Architecture Decision Records

These records capture Phase 3 decisions that would be costly or confusing to
reverse later. They are intentionally few. Routine implementation choices
belong in code, tests, pull requests, and learning guides instead.

Records become accepted when their associated milestone begins. Proposed records
guide future work without pretending that unbuilt platform details are settled.
